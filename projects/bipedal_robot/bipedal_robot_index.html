Bipedal Self Stabilizing Robot

Independent robotics project exploring a wheeled biped-style robot with bending legs, self-stabilizing control, compliant joint concepts, and practical mechanical packaging.

Project Goal

This active development project is focused on building a compact wheeled biped-style robot that can balance, steer, and eventually use leg motion as part of its behavior. The goal is to practice full-system robotics design: mechanism layout, actuator selection, sensor feedback, control tuning, electronics packaging, and iterative prototyping.

The early concept work is centered on making the robot mechanically expressive while keeping the first build achievable. That means separating the project into manageable subsystems: body structure, head and electronics layout, leg actuation, joint compliance, wheel drive, and stabilization control.

Development Focus

The project is currently in the mechanical concept and architecture phase. Key engineering questions include how the leg linkage should bend, how much compliance should be built into the joints, how the electronics should be packaged, and how the wheel motors and IMU feedback will support self-balancing control.

Next Steps

The next stage is to turn the sketches into CAD, validate the leg geometry, prototype the joint and pulley behavior, and begin electronics testing around sensing and motor control.
